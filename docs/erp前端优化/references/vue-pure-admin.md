# vue-pure-admin Reference

Source:

- https://github.com/pure-admin/vue-pure-admin

## Key Notes

- vue-pure-admin is an open-source admin template using Vue 3, Vite, Element Plus, TypeScript, Pinia, and Tailwind CSS.
- It is a useful reference for modern admin shell structure and route-driven layout.

## What To Borrow

- Modern admin shell discipline.
- Route-aware sidebar state.
- Responsive admin layout ideas.
- Clear separation of layout and page content.

## What Not To Borrow

- Do not add Tailwind only for visual polish.
- Do not copy the full template structure into this project.

## ERP Design Lesson

Admin projects feel polished when the shell is boring in a good way:

- stable nav;
- consistent spacing;
- predictable page width;
- obvious current route;
- clean header actions.
