# QPO 销售匹配订单级工作台退役说明

> 2026-08-10 收口：原订单级销售匹配工作台已删除。销售订单导入自动快照补全保留在导入事务内部执行，不再提供用户手工选择订单、预览和确认的工作台。

## 1. 删除范围

- 不再维护订单级销售匹配页面。
- 不再维护手工选择销售订单、预览差异、确认补全或图纸预览交互。
- 不再维护对应前端 `marketApi` helper、共享订单选择 scope 或页面权限。
- 不再维护后端手工预览 / 确认 Controller 和 DTO。

## 2. 保留规则

销售订单导入仍会自动调用 `SalesOrderAutoSnapshotCompletionService.completeImportedOrder`：

- 只处理导入事务创建的销售订单。
- 只补缺失生产快照，不覆盖销售订单导入事实。
- 已提单或无剩余数量的零件跳过。
- 未命中历史快照不阻断导入和自动提单。
- 组合件父子关系仅在历史来源和当前销售订单子件都完整时写入。

## 3. 下游工作台

自动补全后，业务处理转入既有页面：

- 销售订单管理：查看销售订单头、零件明细、匹配状态、提单行和工艺表行。
- 已提零件：继续获取 MES 物料号和 WMS 库存信息。
- 待产 / 锁库：继续消费 allocation 结果。
- U9同步：按销售订单整单预览和同步。
- 提单表据：查看和导出 RFQ / 销售订单来源提单。

## 4. 验收

- 菜单和路由中不再出现手工销售匹配工作台。
- 销售订单导入后仍能自动补全历史生产快照。
- 自动补全不要求额外用户权限。
- 首页看板不再把销售订单引导到手工治理待办。
