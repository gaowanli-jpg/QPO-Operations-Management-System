# QPO 销售订单自动补全材料字段口径说明

> 2026-08-10 收口：原手工销售匹配页面已删除。本文保留材料字段边界作为销售订单导入自动快照补全的规则说明，不再要求任何手工页面、手工 API 或独立权限。

## 1. 字段边界

销售订单导入模板字段是客户侧事实，自动补全不得覆盖：

- `material_name`：销售订单模板中的材料。
- `description`：销售订单模板中的描述 / 物料描述。
- `surface_treatment`：销售订单模板中的表面处理。
- `drawing_url` / `has_drawing`：销售订单导入绑定或补传图纸结果。
- 数量、价格、客户订单号、客户项目号、内部项目号、交期和备注。

价格字段继续以 `tax_included_unit_price`、`tax_included_total_price`、`untaxed_unit_price` 和 `untaxed_total_price` 为准；自动快照补全不写价格事实。

自动补全只写生产快照字段的空缺值：

- `engineering_material_code`
- `engineering_material_name`
- `engineering_material_type_code`
- `engineering_material_type_name`
- `engineering_material_category`
- `material_shape`
- `material_data`
- `process_route`
- `fee_data`
- `material_gross_weight`
- `part_net_weight`
- `assembly_fee`
- `base_cost`
- `assembly_relation_status`

`match_status` 和 `match_message` 仍用于说明自动补全结果：`已匹配`、`未匹配` 或 `跳过`。

## 2. 自动补全规则

`SalesOrderAutoSnapshotCompletionService.completeImportedOrder` 在销售订单导入事务内执行：

1. 按 `图号 + 版本` 查询最新已提 RFQ 历史快照。
2. 命中后只补空缺生产快照和工程材料身份。
3. 来源缺少材料编码、材料类型、材质分类或材料形态时，不用当前材料字典重新推导。
4. 目标已有销售订单事实字段时保持不变。
5. 来源没有确认物料号时不阻断其他快照补全。
6. 目标已有不同确认物料号时记录冲突，不覆盖。

## 3. 页面影响

手工销售匹配页面退役后，不再存在材料差异预览、字段覆盖确认或补全按钮。用户通过以下页面查看最终结果：

- 销售订单：查看导入事实、匹配状态和匹配说明。
- 已提零件 / 提单表据：查看自动提单后的生产快照。
- U9同步：查看已确认物料号、价格校验和同步阻断原因。
- MES/WMS/待产/锁库：消费提单和 allocation 快照，不回查手工页面。

## 4. 验收

- 自动补全后，销售订单导入材料、描述、表面处理和图纸不被覆盖。
- 命中历史 RFQ 时，工程材料身份、材料形态和材料快照能补齐空缺。
- 未命中历史 RFQ 时，导入和自动提单继续完成。
- 前端和后端不再暴露手工材料差异预览入口。
