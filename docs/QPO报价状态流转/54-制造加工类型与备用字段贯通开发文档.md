# 制造加工类型与备用字段贯通

## 字段与存储

| 页面字段 | JSON 字段 | 数据库列 |
| --- | --- | --- |
| 制造加工类型 | `manufacturingProcessType` | `manufacturing_process_type` |
| 备用字段1 | `reservedField1` | `reserved_field_1` |
| 备用字段2 | `reservedField2` | `reserved_field_2` |
| 备用字段3 | `reservedField3` | `reserved_field_3` |

四项均为可选自由文本，去除首尾空格后最多 120 字符，无枚举或必填约束。
V62 仅为 `item_quote_version`、`sales_order_header`、`sales_order_item` 各添加四个可空 `VARCHAR(120)` 列。
历史数据不回填，已执行的迁移保持不变。

## 新建与追加

- 新单 Excel 导入：步骤 2 填写订单默认值，保存至销售订单头；Excel 四个同名表头提供零件级覆盖值。行值为空或列缺失时继承页面默认值。第一行零件覆盖值不会成为订单头默认值。
- RFQ 议价提单：左侧订单默认信息与右侧零件行均支持输入；零件行先保存到 RFQ 零件。正式生成销售订单时，零件值优先，空值继承本次提单默认值，订单头保留本次默认值。
- Excel 追加到已有销售订单：行值优先，空值继承目标销售订单头，不修改目标头和已有零件行。
- RFQ 追加到已有销售订单：RFQ 零件值优先，空值继承目标销售订单头，不使用议价提单左侧默认信息。
- 锁库拆行生成新的销售订单零件时复制原销售订单零件四项字段，保持普通零件资料完整。

RFQ 正式提单和追加的幂等校验包含四项零件字段，使用批量加载、按零件 ID 排序及长度编码生成摘要。
正式提单按有效继承值计算，因此默认值回存 RFQ 后重复提交仍能复用原结果；同一批次发生字段变化会拒绝复用。

## 查询与维护

销售订单主列表仅增加订单头的“制造加工类型”列；三个备用字段只在详情展示。
详情订单头和零件明细均可独立查看、编辑、清空。修改订单头不覆盖或补写已有零件的四项值；只影响后续新建、追加零件的默认值。
零件 Excel 数据替换、整单字段维护、零件明细导出支持四项字段，导入模板的字段说明注明可选、120 字符及继承规则。
图号、版本永久只读规则不变。

## 权限与审计

不新增接口或权限点：RFQ 维护、替换、正式提单及 RFQ 追加复用 `market:release:create`；新单导入复用 `market:rfq:import-sales-order`；Excel 追加复用 `market:release-append:create`。
销售订单维护与 Excel 替换复用 `market:sales-order:update`，明细导出复用 `market:sales-order:item-detail-export`。
后端继续执行原有权限注解、数据范围和订单可维护状态校验。

字段维护纳入原 `RELEASE_ITEM_ORDER_FIELDS_UPDATE`、`SALES_ORDER_UPDATE`、`SALES_ORDER_ITEM_UPDATE` 及表格替换审计动作；创建和追加沿用原有业务摘要。
日志不添加完整 Excel、外部请求、响应、图纸或凭据。

## 数据边界

提单、Allocation 均不新增或复制四项字段；已提零件、待产零件、锁库零件不新增相关显示列。
MES 物料号获取、MES 生产、WMS、提库存工单、U9 请求及生产任务通知单均不增加四项字段。
以后若执行模块需要这些数据，应关联销售订单零件读取。

## 验收

订单默认“加工A”，Excel/RFQ 零件甲填写“加工B”、零件乙为空：订单头保存“加工A”，甲保存“加工B”，乙保存“加工A”。
订单头改为“加工C”后，甲、乙保持原值；之后追加的空值零件继承“加工C”。
维护零件时清空字段后该行保留空值，不立即重新继承订单头。
