# QPO 销售订单 U9 同步模块开发文档
最后更新：2026-08-11

> 数据中心统一对接阶段 8 收口：销售订单 U9 同步底层调用统一走数据中心，endpoint 为 `U9_SALES_ORDER_SYNC`，链路为 `QPO -> 数据中心 -> U9`。旧 `ERP_U9_*` 仅作为 deprecated fallback，新部署应优先在系统配置的出站接口中维护数据中心连接和该功能 path。

> 2026-08-10 手工模块退役收口：销售订单导入后自动补全历史生产快照并自动生成销售订单来源提单行，销售订单不再手动进入销售匹配或议价提单。价格补齐前不可同步 U9；preview 返回不可同步、展示缺价格原因，提交同步时不调用数据中心或 U9。

> 2026-09-09 U9 价格口径优化：以 `42-销售订单U9同步模块重构开发文档.md` 的最小已验证契约为准。U9 销售订单默认使用含税单价：`IsPriceIncludeTax=true`，`FinallyPriceTC = sales_order_item.tax_included_unit_price`；也可由操作员切换为未税单价：`IsPriceIncludeTax=false`，`FinallyPriceTC = sales_order_item.untaxed_unit_price`。QPO 仍不发送税率、税额、金额汇总、客户料号、图号、版本、单位、换算率或订单价字段。

> 2026-08-11 权限与日志收口：本轮不新增用户权限，不新增 `common:*`。列表、选项和预览属于正常读取，不写操作日志；保存 Seller / SaleDepartment、提交同步和结果核对均复用 `market:u9-sync:submit`，并只记录安全摘要。

> 2026-08-11 两级工艺主数据口径延续：U9 同步仍只消费 `sales_order_header / sales_order_item` 的销售订单字段、已确认物料号和本次选择的价格口径，不把 QPO 工艺路线发送给 U9。派生销售订单或导入销售订单中的工艺快照只用于 QPO 内部核价、提单、MES/WMS、待产/锁库和追溯展示。

## 1. 背景与结论

`14-销售订单独立主表开发文档.md` 已确认销售订单使用独立主表 `sales_order_header` 和独立零件表 `sales_order_item`，不再写入 RFQ 主表 `order_rfq`，也不再写入 RFQ 零件表 `item_quote_version`。

销售订单进入 QPO 后的主链路为：

```text
新单导入 -> 自动补全历史生产快照 -> 自动生成已提零件 -> 获取 MES 物料号 -> WMS / 待产 / 锁库 -> U9 同步 -> 提单表据
```

其中 U9 同步不能继续放在“新单导入”里，也不能把导入模板里的 `material_no` 直接当成 U9 正式物料号。销售订单真正可同步 U9 的前提是：

1. 销售订单已经生成正式 QPO 提单。
2. 销售订单头和销售订单零件已经保存导入时的客户、订单、数量、价格、交期和项目字段。
3. 提单行 `order_delivery_ticket` 已经通过 MES 获取或确认 `material_no`。
4. MES 成功后把正式物料号和确认状态回写到 `sales_order_item`。
5. U9 同步运行时只读取 `sales_order_header` / `sales_order_item` 组装请求。
6. U9 明细行的 `ItemCode` 使用 `sales_order_item.material_no`，但必须同时满足 `material_no_status = 已确认`。
7. U9 明细行必须具备本次选择的价格字段：默认含税模式校验 `sales_order_item.tax_included_unit_price`，未税模式校验 `sales_order_item.untaxed_unit_price`。所选价格为空时，preview 返回不可同步，提交同步直接拒绝，不调用数据中心或 U9。

因此新增独立左侧模块 **U9同步**，位置放在 **议价提单** 和 **提单表据** 之间：

```text
市场
  新单导入
  报价处理
  议价提单
  U9同步
  提单表据
  订单管理
  历史订单
  已提零件
  锁库零件
```

核心结论：

- U9 同步只面向销售订单，不面向 RFQ。
- U9 同步按 **销售订单整单** 触发，不按提单行、提单批次或零件单独触发。
- 整单同步要求销售订单已经全部生成提单，即销售订单头状态为 `已生成提单`。
- 如果销售订单仍为 `已报价` 或 `部分已提单`，页面可展示原因，但不允许提交 U9 同步。
- 如果任意销售订单零件缺少已确认的 `material_no`，整单不可同步，并返回明确的销售订单零件 ID、图号、版本和缺失原因。
- 如果任意销售订单零件在本次 U9 价格口径下缺少对应单价，整单不可同步，并返回明确的销售订单零件 ID、图号、版本和缺少价格原因；含税模式不拿未税价兜底，未税模式也不拿含税价兜底。
- 同步成功后回写 `sales_order_header.u9_sync_status`、`u9_order_id`、`u9_order_code` 和 `u9_sync_message`。
- 同步失败不影响已生成的 QPO 提单记录，也不回滚 MES/WMS 结果。
- 日志和审计只记录摘要，不记录 U9 token、密钥、Authorization header、完整请求体或完整响应体。

## 2. 目标

- 新增独立左侧模块 **U9同步**，放在 **议价提单** 和 **提单表据** 之间。
- 页面只展示销售订单，不展示 RFQ 订单选择入口。
- 支持按客户、销售订单号、客户订单号、内部项目号、U9 同步状态、物料号就绪状态筛选销售订单。
- 支持预览整张销售订单即将同步到 U9 的订单头和明细行。
- U9 明细全部来自销售订单导入形成的 `sales_order_item`，`ItemCode` 使用已确认回写的 `sales_order_item.material_no`。
- 整单同步时校验所有销售订单零件均已取得并确认 `material_no`。
- 同步成功、失败、部分失败均返回销售订单号、U9 编码、失败摘要和行级问题。
- 保留失败重试能力，避免已同步成功的销售订单重复创建 U9 订单。
- 将现有 `SalesOrderU9SyncService` 从“新单导入附属能力”收口为独立 U9 同步模块的后端服务。
- 更新权限清单、日志运维说明和销售订单主流程文档。

## 3. 非目标

- 不在 U9 同步模块生成 QPO 提单。
- 不在 U9 同步模块获取 MES 物料号；MES 物料号仍由 **已提零件** 模块触发和回写。
- 不在 U9 同步模块提交 WMS 锁库；WMS 仍由 **已提零件** 或既有下游入口触发。
- 不直接同步 RFQ 主订单到 U9；RFQ 议价提单生成的 `RFQ_RELEASE` 派生销售订单可以进入本模块同步。
- 不把销售订单写入 `order_rfq`。
- 不把销售订单零件写入 `item_quote_version`。
- 不把导入模板或人工写入但未确认的 `sales_order_item.material_no` 当成 U9 正式物料号。
- 第一版不支持按提单批次分多次生成 U9 订单；如果业务后续确认需要分批同步，应新增独立状态和幂等设计。

## 4. 数据事实来源

### 4.1 U9 运行时数据源

U9 同步运行时只读取销售订单独立主表和零件表：

| 表 | 作用 |
| --- | --- |
| `sales_order_header` | 销售订单头，保存客户、单据类型编码、订单号、U9 同步状态和 U9 返回编码。 |
| `sales_order_item` | 销售订单零件，保存图号、版本、数量、价格、交期、销售料号、生产快照、正式 `material_no` 和物料号确认状态。 |

### 4.2 提单 / MES 回写上游

销售订单生成正式 QPO 提单后，提单行仍进入统一提单事实表；但该表只作为 MES 获取物料号的需求池和回写上游，不作为 U9 同步运行时主查询来源：

| 表 | 关键字段 | 作用 |
| --- | --- | --- |
| `order_delivery_ticket` | `source_type` | `SALES_ORDER` 表示该提单行来源于销售订单。 |
| `order_delivery_ticket` | `source_order_id` | 指向 `sales_order_header.id`。 |
| `order_delivery_ticket` | `source_item_id` | 指向 `sales_order_item.id`。 |
| `order_delivery_ticket` | `material_no` | MES 获取或确认后的正式物料号，成功后必须回写到 `sales_order_item.material_no`。 |

### 4.3 物料号回写规则

MES 物料号同步成功后：

1. 必须写入 `order_delivery_ticket.material_no`。
2. 如果 `order_delivery_ticket.source_type = SALES_ORDER`，必须通过 `source_item_id` 回写 `sales_order_item.material_no`。
3. 同步回写 `sales_order_item.material_no_status = 已确认`。
4. 同步回写物料号来源追溯字段，例如 `material_no_source = MES_TICKET`、`material_no_source_ticket_id = order_delivery_ticket.id`、`material_no_synced_at = 当前时间`。
5. U9 同步组装请求时只读取 `sales_order_header` / `sales_order_item`；不再实时查询 `order_delivery_ticket` 获取物料号。
6. 如果 `sales_order_item.material_no` 有值但 `material_no_status != 已确认`，整单仍视为不可同步。

原因：物料号确认发生在提单 / MES 阶段；该阶段负责把正式物料号沉淀回销售订单零件表。U9 同步阶段只消费销售订单最终状态，避免运行时反复跨 `order_delivery_ticket` 取数。

### 4.4 `sales_order_item` 物料号确认字段

建议给 `sales_order_item` 增加以下字段：

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `material_no_status` | `VARCHAR(30) NOT NULL DEFAULT '未确认'` | 物料号确认状态：`未确认`、`已确认`、`获取失败`。 |
| `material_no_source` | `VARCHAR(30)` | 物料号来源，MES 提单回写时为 `MES_TICKET`。 |
| `material_no_source_ticket_id` | `BIGINT` | 回写来源提单行 `order_delivery_ticket.id`，用于追溯。 |
| `material_no_synced_at` | `TIMESTAMP` | MES 成功回写销售订单零件的时间。 |
| `material_no_message` | `TEXT` | 物料号回写或失败摘要，避免记录完整外部响应。 |

字段规则：

- 导入模板带入 `material_no` 时，默认 `material_no_status = 未确认`，除非业务明确该值已经过 MES / 主数据确认。
- MES 成功回写时，`material_no_status = 已确认`。
- MES 失败且可定位到销售订单零件时，可写 `material_no_status = 获取失败` 和简短 `material_no_message`。
- U9 同步只接受 `material_no_status = 已确认` 且 `material_no` 非空的销售订单零件。

## 5. 业务流程

### 5.1 页面流程

```text
进入 U9同步
  -> 筛选销售订单
  -> 选择一张销售订单
  -> 查看同步就绪摘要
  -> 点击“预览U9同步”
  -> 后端读取 sales_order_header / sales_order_item 组装预览
  -> 页面展示销售订单头、销售订单零件、已确认物料号、阻断原因
  -> 若整单满足条件，点击“同步U9”
  -> 后端调用 U9
  -> 回写 sales_order_header U9 状态和 U9 编码
  -> 页面刷新同步结果
```

### 5.2 状态规则

| 销售订单状态 | U9 同步处理 |
| --- | --- |
| `已报价` | 不可同步，提示“尚未生成 QPO 提单”。 |
| `部分已提单` | 不可整单同步，提示“销售订单仍存在未提单数量，需全部生成提单后再同步 U9”。 |
| `已生成提单` | 可进入物料号完整性校验。 |
| `已废弃` | 不进入可选列表，不允许同步。 |

### 5.3 U9 同步状态

`sales_order_header.u9_sync_status` 建议沿用或规范为：

| 状态 | 含义 |
| --- | --- |
| `未同步` | 尚未提交 U9。 |
| `同步中` | 已提交 U9 调用，处理中。 |
| `结果待确认` | 外部创建结果不明确，只允许核对，不允许直接重发创建请求。 |
| `已同步` | U9 返回成功，已回写 U9 编码。 |
| `同步失败` | U9 调用失败或同步前校验失败，可重试。 |

重试规则：

- `未同步`：允许同步。
- `同步失败`：允许重试。
- `同步中`：不允许重复提交，提示稍后刷新。
- `结果待确认`：不允许直接同步，只能通过核对动作确认 U9 是否已有同 DocNo 订单。
- `已同步`：默认不允许再次创建 U9 订单。

## 6. U9 组装规则

### 6.1 订单头

U9 订单头从 `sales_order_header` 和客户主数据快照组装：

| U9 字段 | QPO 来源 | 说明 |
| --- | --- | --- |
| `OtherID` | `sales_order_header.sales_order_no` | QPO 内部销售订单号，用作幂等追溯。 |
| `DocNo` | `sales_order_header.document_no` | 如为空则由 U9 返回后回写。 |
| `BusinessDate` | `sales_order_header.sales_order_date` | 为空时可用当前日期兜底。 |
| `OrderBy` | `sales_order_header.customer_code` | 来自客户主数据 `customer_code`，缺失则不可同步。 |
| `DocumentType` | `sales_order_header.document_type_code` | 页面选择或输入，默认 `SO06`。 |
| `Seller` | `sales_order_header.u9_seller_code` | 可选；页面选择 U9 销售员后保存，空值不发送。 |
| `SaleDepartment` | `sales_order_header.u9_sale_department_code` | 可选；销售员可自动带出部门，部门仍可独立修改或清空。 |
| `IsPriceIncludeTax` | 操作员选择的 U9 价格口径 | 未税模式为 `false`，含税模式为 `true`。 |

### 6.2 明细行

U9 明细行以 `sales_order_item` 为唯一运行时明细来源。提单行只在 MES 获取物料号阶段回写销售订单零件，不在 U9 同步阶段参与明细组装：

| U9 字段 | QPO 来源 | 说明 |
| --- | --- | --- |
| `DocLineNo` | QPO 系统行号 `sales_order_item.line_no` | 入库时按识别到的销售订单零件行顺序生成，订单内从 1 连续递增；不沿用客户 Excel 原始“序号”。 |
| `ItemCode` | `sales_order_item.material_no` | 正式物料号，必须已由 MES 提单流程回写并满足 `material_no_status = 已确认`。 |
| `OrderByQtyTU` | `sales_order_item.qty` | 整单同步数量来自销售订单零件主表。 |
| `OrderByQtyPU` | `sales_order_item.qty` | 与交易单位数量一致。 |
| `FinallyPriceTC` | 本次选择的销售订单零件单价 | 未税模式取 `sales_order_item.untaxed_unit_price`；含税模式取 `sales_order_item.tax_included_unit_price`，所选字段必须非空。 |
| `RequireDate` | `sales_order_item.internal_delivery_date` / `customer_delivery_date` | 使用销售订单导入交期。 |
| `ShipPlanQtyTU` | `sales_order_item.qty` | 整单同步发运计划数量来自销售订单零件主表。 |
| `DescFlexField.PrivateDescSeg1` | `sales_order_header.customer_project_no` | U9 私有字段：客户项目号。 |
| `DescFlexField.PrivateDescSeg2` | `sales_order_header.customer_order_no` | U9 私有字段：客户采购订单号。 |
| `DescFlexField.PrivateDescSeg3` | `sales_order_header.internal_project_no` | U9 私有字段：内部项目号。 |
| `DescFlexField.PrivateDescSeg4` | `sales_order_item.customer_delivery_date` | U9 私有字段：客户交期。 |
| `DescFlexField.PrivateDescSeg5` | `sales_order_item.internal_delivery_date` | U9 私有字段：内部交期。 |
| `DescFlexField.PrivateDescSeg9` | 本次同步价格 | 与 `FinallyPriceTC` 使用同一价格口径，便于 U9 侧核对。 |
| `DescFlexField.PubDescSeg2` | `sales_order_item.remark` | U9 公共扩展字段：销售备注。 |

价格校验规则：

- 预览和提交默认把 `sales_order_item.untaxed_unit_price` 作为 U9 价格来源。
- 操作员切换为未税模式后，`IsPriceIncludeTax=false`，`FinallyPriceTC` 改取 `sales_order_item.untaxed_unit_price`。
- 所选价格字段为空时，行级和整单阻断原因均明确为“未税单价为空”或“含税单价为空”。
- 两种模式互不兜底：未税模式不读取含税价，含税模式不读取未税价。
- 不发送 `OrderPriceTC`、税额、未税金额或含税金额。
- 提交接口必须重新执行强校验，不能依赖前端预览结果；校验失败时不调用数据中心或 U9。

### 6.3 数量口径

第一版按销售订单整单同步，要求：

- 销售订单头状态为 `已生成提单`。
- 该销售订单下所有有效 `sales_order_item` 均已完成提单。
- U9 明细行来自 `sales_order_item`，不再通过 `order_delivery_ticket.source_item_id` 实时查找物料号。
- 第一版要求整张销售订单全部提单完成后再整单同步，因此同步数量直接使用 `sales_order_item.qty`。
- 每条有效 `sales_order_item` 必须存在 `material_no`，且 `material_no_status = 已确认`。
- `material_no_source_ticket_id` 只用于追溯是哪条提单行完成 MES 回写，不参与 U9 组装查询。

## 7. 后端设计

### 7.1 新增控制器

建议新增：

```text
quote-backend/src/main/java/com/machining/quote/controller/SalesOrderU9SyncController.java
```

基础路径：

```text
/api/market/u9-sync
```

接口建议：

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| `GET` | `/options` | `market:u9-sync:view` | 读取组织 `101` 下有效 Seller 和 SaleDepartment 选项；正常读取，不写操作日志。 |
| `GET` | `/orders` | `market:u9-sync:view` | 分页查询销售订单同步列表。 |
| `GET` | `/orders/{salesOrderId}/preview` | `market:u9-sync:view` | 预览整单 U9 同步数据和阻断原因，不调用 U9。 |
| `PUT` | `/orders/{salesOrderId}/assignment` | `market:u9-sync:submit` | 保存 Seller / SaleDepartment，可空，可独立清空或覆盖。 |
| `POST` | `/orders/{salesOrderId}/sync` | `market:u9-sync:submit` | 提交单张销售订单整单同步。 |

### 7.3 同步前校验

`syncSalesOrders(...)` 在调用 U9 前必须校验：

1. 销售订单存在。
2. 当前用户具有该销售订单数据权限。
3. `sales_order_header.status = 已生成提单`。
4. `customer_code` 不为空。
5. `document_type_code` 不为空。
6. `u9_sync_status != 已同步`。
7. 不存在当前 `u9_sync_status = 同步中` 的并发请求。
8. 所有有效 `sales_order_item` 均已提单完成，可通过 `status = 已生成提单`、`released_qty = qty`、`remaining_qty = 0` 等销售订单零件状态判断。
9. 所有有效 `sales_order_item.material_no` 均非空。
10. 所有有效 `sales_order_item.material_no_status = 已确认`。
11. 所有有效 `sales_order_item.material_no_source = MES_TICKET`，或满足后续明确批准的正式物料号确认来源。
12. 每条销售订单零件的 `untaxed_unit_price` 非空；`tax_included_unit_price` 有值不能绕过该校验。

校验失败时：

- 不调用 U9。
- 回写 `u9_sync_status = 同步失败` 和简短 `u9_sync_message`。
- 返回明确可读的阻断原因。
- 不修改 `order_delivery_ticket`。

### 7.4 幂等与并发

- 使用 `sales_order_header.id` 加行锁或乐观状态更新，避免重复提交。
- 同步开始前将 `u9_sync_status` 从 `未同步` / `同步失败` 更新为 `同步中`。
- 如果状态更新影响行数为 0，说明状态已变化，应拒绝本次提交。
- U9 请求的 `OtherID` 使用 `sales_order_header.sales_order_no`，用于 U9 侧幂等追溯。
- `已同步` 的销售订单默认不可重试；如后续确需重新推送，应新增管理员级“强制重推”权限和审计，不在第一版实现。

## 10. 数据权限

U9 同步模块只能访问当前用户可见客户范围内的销售订单。

规则：

- 列表从 `sales_order_header` 过滤。
- 预览、保存 Seller / SaleDepartment、同步和核对必须重新校验 `sales_order_header` 数据权限。
- U9 列表、预览、保存、同步和核对运行时只查询 `sales_order_header` / `sales_order_item`。
- `order_delivery_ticket` 只在 MES 物料号回写时通过 `source_type/source_item_id` 定位销售订单零件；U9 模块不应为了组装请求实时 join 提单表。
- 数据权限为 `NONE` 时列表返回空。
- 越权传入 `salesOrderId` 时返回 403 或安全错误，不泄露图号、物料号、U9 状态等业务细节。

### 阶段 8 收口补充：支持 RFQ 议价提单派生来源

U9 同步订单列表、预览和整单同步同时支持 `DIRECT_IMPORT`（销售订单导入）与 `RFQ_RELEASE`（RFQ 议价提单派生）来源。派生销售订单仍读取 `sales_order_header / sales_order_item`，不从 RFQ ticket 临时拼装请求。

两种来源均严格校验已确认物料号、本次 U9 价格口径对应单价、客户编码和单据类型编码；校验失败时不调用数据中心或 U9。U9 成功或失败只回写销售订单 U9 状态，不修改 RFQ 报价状态。复用现有 `market:u9-sync:*` 权限和数据范围，本次不新增权限。
