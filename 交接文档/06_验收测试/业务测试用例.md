## 2. 测试账号

测试时至少准备：

| 系统 | 角色 | 用途 |
| --- | --- | --- |
| ERP | ADMIN | 用户管理、报价模板、全流程兜底 |
| ERP | MARKET | 新单导入、报价单、提单 |
| ERP | ENGINEER | 材料工艺核价 |
| APS | ADMIN | 同步、库存、派工、用户权限 |

生产环境首次验收时不得长期使用默认密码。默认密码仅用于初始化和验证改密流程。

## 3. 测试数据准备

建议准备一套小型测试订单：

| 数据 | 要求 |
| --- | --- |
| 客户 | 使用一个明确测试客户，例如 `测试客户A` |
| 零件 | 至少 3 个零件 |
| 版本 | 至少包含空版本或普通版本 |
| 数量 | 包含小批量和较大数量 |
| 图纸 | 至少上传 1 个 PDF 图纸 |
| 材料 | 至少包含 2 种材料 |
| 工艺 | 至少包含 2 个工时工艺和 1 个非工时费用项 |
| APS 零件库存 | 至少一条库存充足、一条库存不足、一条无库存 |
| APS 材料库存 | 至少一条材料充足、一条材料不足 |
| APS 部门 | 至少一个生产部门、一个外协部门 |
| APS 机台 | 至少一个机台并配置工艺能力 |
